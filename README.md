# Welcome to Krify

A responsive, accessible single-page website built with HTML5, CSS3 and vanilla JavaScript. No frameworks or external libraries.

## Structure

```
index.html
css/styles.css
js/main.js
README.md
```

## Features

- Header with Krify branding and a responsive, keyboard-accessible navigation (mobile menu toggle, Escape to close)
- Hero section with welcome heading and call-to-action
- Services section with responsive cards (1 / 2 / 3 columns)
- About Krify section
- Contact form with client-side validation (required fields, email format, minimum lengths, inline error messages)
- Footer with the current year, set by JavaScript
- Skip link, semantic landmarks, visible focus styles, reduced-motion support

## Running locally

Open `index.html` in a browser. No build step is needed.

## Notes

- The contact form is a front-end demo. It validates input but does not send data anywhere.
- Code has been reviewed by inspection only. Cross-browser and device testing in a real browser is still to be done.
